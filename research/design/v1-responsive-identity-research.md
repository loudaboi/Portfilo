# Portfilo Responsive Identity Research

_Last updated: 2026-09-14_

## Purpose

Record the research logic that led to the founder-approved Responsive Identity direction.

This is research evidence, not a source of final visual decisions by itself.

## Research conclusion

The rejected homepage demonstrated that a design system built primarily from dark neutrals, large sans-serif typography, thin rules, whitespace, and reveal motion can be technically polished while still feeling generic.

The stronger contemporary references reviewed during the reset share a different pattern:

- a clear creative point of view;
- identity expressed through behavior, not only static assets;
- motion that changes state or spatial relationships;
- typography used as identity;
- real product/editorial media carrying prestige;
- controlled differences between site surfaces;
- one memorable behavior rather than many decorative effects.

## Reference lessons

### DIA

Useful lesson:

Identity can be generated, responsive, kinetic, and systemic rather than applied as a fixed logo.

Relevant work included generative and kinetic typographic systems such as Nuits Sonores, SPACE10, and Chaumont Biennale.

Reference:

https://dia.tv/

### Studio Dumbar / DEPT

Useful lesson:

Variable typography and motion physics can become recognizable brand behavior.

Relevant work included Google Sans Flex and dynamic identity systems where typography responds to input.

Reference:

https://studiodumbar.com/

### Studio K95

Useful lesson:

Portfolio navigation itself can become the memorable interaction instead of a conventional project grid.

Do not copy the 3D/chrome/blue aesthetic literally.

Reference:

https://studio-k95.com/

### MetaLab / Calvin Klein

Useful lesson:

A restrained interface can still feel premium when content, media, composition, and the product world carry the visual authority.

Reference:

https://www.metalab.com/work/calvin-klein

### Teenage Engineering

Useful lesson:

A website can derive its identity directly from the company/product language rather than from generic luxury styling.

Technical information, industrial details, labels, photography, and interface behavior can all belong to one coherent world.

Reference:

https://teenage.engineering/

### Nothing / CMF

Useful lesson:

Engineering detail and exposed functional logic can become aesthetic identity when it is authentic to the product.

Reference:

https://nothing.tech/

### Locomotive

Useful lesson:

Typography, composition, and movement can create an expressive studio experience without reducing every project to standardized cards.

Reference:

https://locomotive.ca/

### Fashion / cultural digital experiences

Useful lesson:

Premium does not require visual uniformity. Different campaigns, stories, or product worlds can have different atmospheres while the brand remains coherent.

This supports allowing Work, Journal, and Hustle to behave differently under one identity system.

## Rejected interpretation of silver

Silver should not be interpreted as a requirement for literal brushed metal, futuristic hardware, or chrome-heavy UI.

The discarded generated concept demonstrated this failure mode.

Silver may instead be explored through:

- neutral tonal relationships;
- controlled highlight behavior;
- typographic treatment;
- light response;
- a single digital material cue;
- motion/state changes.

## Design-process correction

Previous process:

`tokens -> grid -> sections -> CSS -> reveal motion`

Revised process:

`idea -> identity -> signature behavior -> prototype -> content/media -> composition -> system -> implementation`

The homepage should not be rebuilt until the earlier stages are approved.

## Selected direction

Founder-approved:

**Responsive Identity**

Supporting research territories retained only as references:

- Software Instrument;
- Spatial Editorial.
