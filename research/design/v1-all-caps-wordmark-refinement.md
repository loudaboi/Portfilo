# Portfilo v1 All-Caps Wordmark Refinement

_Last updated: 2026-09-14_

## Status

**FOUNDER REVIEW ACTIVE**

## Context

The founder selected **A — Perimeter Field** as the homepage structural direction.

Reviewing the approved title-case Noto Serif Display wordmark inside that structure exposed a new concern: the title-case serif treatment reads too editorial/fashion-publication-like beside Mona Sans and the selected spatial system.

Only the wordmark is reopened.

Still locked:

- Sharp Ornamental 01 emblem;
- Mona Sans website typography;
- Perimeter Field homepage structure;
- monochrome-first identity behavior.

## Reference observation

The VIVET reference that triggered this discussion uses a restrained all-caps serif wordmark beside an independent ornamental symbol.

The goal is not to copy VIVET lettering. The useful principle is:

**all-caps wordmark + independent symbol + clear separation between brand typography and interface typography**

## Candidates

### A — Noto Serif Display / ALL CAPS

Purpose:

Preserve continuity with the approved wordmark family while changing capitalization, tracking, and proportion.

Character:

- refined;
- compact;
- high-contrast serif;
- closest evolution of the current identity.

Risk:

May still retain more fashion/editorial character than desired.

### B — Source Serif 4 / ALL CAPS

Purpose:

Keep the serif identity signal but reduce delicacy and editorial pressure.

Character:

- calmer;
- sturdier;
- less fashion-coded;
- still clearly distinct from Mona Sans.

Risk:

Could become too traditional if spacing and weight are not controlled.

### C — Archivo Semi-Condensed / ALL CAPS

Purpose:

Test whether the wordmark should move fully away from serif identity.

Character:

- technical;
- compact;
- studio/software-like;
- least editorial.

Risk:

May compete too directly with Mona Sans and weaken separation between brand and interface typography.

## Review surfaces

Each candidate should be judged as:

1. wordmark alone;
2. emblem + wordmark;
3. actual small header scale;
4. ink on off-white;
5. off-white on ink.

## Decision rule

Select the candidate that best balances:

- independent brand recognition;
- compatibility with Sharp Ornamental 01;
- separation from Mona Sans UI typography;
- small-scale legibility;
- premium restraint without fashion-editorial overcoding;
- fit with Perimeter Field.

Do not update production vectors or runtime assets until founder selection.
