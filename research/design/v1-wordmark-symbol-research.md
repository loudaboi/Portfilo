# Portfilo Wordmark + Symbol Research

_Last updated: 2026-09-14_

## Status

**RESEARCH / SUPPORTING EVIDENCE**

## Objective

Identify useful principles for a simple premium wordmark + standalone symbol system without copying fashion-brand aesthetics literally.

## Key findings

### Symbol and wordmark should share form logic

Pentagram's Viren identity demonstrates a simple symbol that can embed within the wordmark and work independently across scales and applications.

Reference:
https://www.pentagram.com/work/viren

Portfilo implication:

Prefer a symbol derived from distinctive wordmark geometry rather than a decorative icon added afterward.

### Small custom lettering decisions can create the identity

Pentagram's Pyer Moss identity uses a restrained sans wordmark with specific optical modifications and a symbol related to the same structural language.

Reference:
https://www.pentagram.com/work/pyer-moss

Portfilo implication:

The entire wordmark does not need to be expressive. One or two carefully authored letter relationships may be enough.

### Premium can be quiet and highly functional

Pentagram's Rolls-Royce work refined the wordmark while keeping separate marks for different applications. Each identity asset has an explicit job and is optimized across scales.

Reference:
https://www.pentagram.com/work/rolls-royce-3/story

Portfilo implication:

A wordmark and symbol do not need to be fused into one clever trick. They need a coherent relationship and clear roles.

### Distinctive symbols work best when they encode a real system

Pentagram's Plenaire symbol derives from the brand's product/state system rather than an arbitrary beauty mark.

Reference:
https://www.pentagram.com/work/plenaire

Studio Dumbar's Modyfi identity similarly uses a core symbol whose geometry repeats across grids, layouts, shapes, numbers, and icons.

Reference:
https://studiodumbar.com/work/modyfi

Portfilo implication:

If the standalone mark cannot generate useful behavior or visual grammar beyond the favicon, it may not be strong enough.

### Bespoke type can extend beyond the logo

Pentagram's Liberty identity uses a refined logotype as the source for a custom display typeface and wider typographic behavior.

Reference:
https://www.pentagram.com/work/liberty

Portfilo implication:

The final wordmark may eventually seed wider typographic details, but this should emerge from a strong mark first rather than being designed as a full type system prematurely.

## Vivet reference boundary

The founder's Vivet reference is treated as a principle:

- simple wordmark;
- compact stylistic emblem;
- strong standalone use;
- premium restraint;
- confidence in monochrome application.

Do not copy Vivet's exact letterforms, emblem geometry, fashion positioning, or merchandising language.

## Portfilo design test

A candidate should pass this test:

> If all website motion and effects disappear, are the wordmark and symbol still strong enough to carry Portfilo?

If not, the identity is relying on presentation rather than design.
