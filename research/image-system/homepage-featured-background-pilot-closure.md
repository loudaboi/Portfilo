# Homepage Featured Background Pilot Closure

_Last updated: 2026-09-04_

_Status: CLOSED FOR V0 / NO GENERATED HOMEPAGE IMAGE_

## Decision

Louda Tuppal ended the generated-image homepage pilot after repeated candidate failures.

For Portfilo v0:

- do not use image generation for the homepage featured-story background;
- keep the existing black, typography-led feature panel without a generated image;
- do not generate additional homepage candidates unless Louda explicitly reopens the experiment later;
- generated imagery is not a v0 launch dependency.

## Why the pilot was closed

Multiple iterations failed despite progressively stricter briefs and execution prompts.

Observed failure modes included:

- physically or spatially illogical structures;
- scenes that became staged or overdesigned;
- excessive visual detail and invented props;
- outputs that looked like generic AI-composed workplace imagery rather than controlled editorial art;
- prompt/context contamination in earlier tests;
- inability to achieve reliable visual logic while also preserving the intended restraint and atmosphere.

The cost in review time and iteration was no longer justified for a decorative homepage surface whose semantic job is already handled by real HTML typography.

## V0 homepage treatment

The homepage featured panel remains:

`TYPOGRAPHY-LED / NO BACKGROUND IMAGE`

The panel already communicates:

- editorial type;
- topic;
- author;
- story linkage;
- Portfilo visual identity through typography, color, spacing, and layout.

No image is required for v0 completion.

## Future image options

If Portfilo revisits imagery after v0, prefer sources where visual logic and authorship can be controlled directly, such as:

- owned photography;
- properly licensed editorial photography;
- commissioned/manual illustration;
- diagrams or charts built from verified information;
- deterministic graphic compositions created directly in code/design tools.

Image generation should not be treated as the default solution merely because it is available.

## Authority of generated candidates

All generated homepage candidates from this pilot have:

`ZERO FINAL-ASSET AUTHORITY`

They must not be implemented or treated as approved Portfilo visual precedent.

## Reopening rule

Do not restart homepage image generation automatically.

The experiment may resume only after a new explicit human decision from Louda Tuppal.
