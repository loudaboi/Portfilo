# Portfilo v1 Image System

_Last updated: 2026-09-14_

## Principle

Images must perform a real job: proof, documentation, explanation, context, or composition.

Do not add an image merely because a layout has space for one.

## Work

Priority:

1. real product/interface capture;
2. real workflow/product footage;
3. browser/window framing when context matters;
4. device framing only when device context matters.

Do not use decorative 3D or generic mockups to compensate for weak project evidence.

Never fabricate client UI, outcomes, usage data, or operating environments.

## Hustle

Use authentic portraits, workplaces, documents, and subject-provided context.

Natural color is allowed.

Do not generate documentary likenesses of real subjects or fake environments that could be mistaken for reporting evidence.

## Journal

Use images only when they add explanatory, documentary, data, or conceptual value.

Generated editorial illustration must not be presented as documentary evidence.

## Generated imagery

Before generation, establish:

- the visual job;
- factual boundaries;
- what must not be implied;
- approved composition direction.

Disclose generation where a reasonable reader could otherwise mistake the result for documentary photography or evidence.

## Asset discipline

- retain source provenance/credit where required;
- use responsive delivery;
- remove orphaned assets from the active branch after reference checks;
- do not recolor real project/client material solely to enforce the Portfilo neutral shell.
