## Review rule

A backlog item may enter implementation only when one of these is true:

1. a real user or editorial workflow needs it;
2. traction exposes a current constraint;
3. it materially improves trust, distribution, revenue, or operating efficiency;
4. the current architecture can no longer satisfy a validated requirement cleanly.

When an item is promoted, update `docs/V0_SCOPE.md` or create the appropriate next-phase scope before building it.
