## Raster delivery pack

Raster exports are convenience outputs generated from the approved vector masters.

They include transparent wordmark/emblem/lockup PNGs plus favicon, Apple-touch, and social-avatar variants.

The SVG masters remain the identity source of truth.

No neutral-silver production export is canonical yet because an exact silver value has not been founder-approved.

## Rules

- do not modify the emblem geometry without a new identity decision;
- do not replace the all-caps wordmark treatment without a new identity decision;
- prefer master `currentColor` SVGs in interfaces where possible;
- use fixed variants when external SVG color inheritance is unavailable;
- primary browser favicon remains transparent;
- platform-specific filled tiles are secondary applications only.
