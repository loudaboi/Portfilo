## Rules

- do not modify the emblem geometry without a new identity decision;
- do not replace the wordmark treatment without a new identity decision;
- prefer master `currentColor` SVGs in interfaces where possible;
- use fixed variants when external SVG color inheritance is unavailable;
- primary browser favicon remains transparent;
- platform-specific filled tiles are secondary applications only.
